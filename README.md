# 🎲 Juego de beber con amigos

[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)](https://developer.android.com/)
[![Status](https://img.shields.io/badge/Status-Completed-brightgreen)](#)

Aplicación móvil nativa para Android diseñada para dinamizar reuniones sociales y juegos en grupo. Reúne múltiples modalidades de juego populares (Verdad o Reto, Yo Nunca, etc.) con generación aleatoria de preguntas y flujos de juego interactivos.

---

### 🚀 Características Principales

- 🎭 **Múltiples Modos de Juego:** Integración de dinámicas variadas (Verdad o Reto, Yo Nunca...) en una sola plataforma.
- 🔀 **Motor de Preguntas Aleatorias:** Algoritmos de selección para evitar la repetición de tarjetas e historias durante una partida.
- 👥 **Gestión de Participantes:** Configuración intuitiva de jugadores y turnos dinámicos.
- 🎨 **UI Dinámica y Fluida:** Diseño de interfaz enfocado en la usabilidad en entornos grupales y nocturnos.

---

### 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Kotlin
- **Plataforma:** Android SDK
- **Interfaz de Usuario:** XML Layouts / Material Design Components
- **Arquitectura:** Componentes de arquitectura de Android (Activities, Collections, State Management)
- **IDE:** Android Studio
